# Videos Chapters & Logos

WordPress plugin that displays MP4 videos with a logo and chapter markers using Video.js.

## Features

- Display MP4 videos.
- Add a logo and chapter markers.
- Set a poster image.
- Configure autoplay, muted playback, and looping.
- Select a Video.js theme.
- Manage videos from the WordPress dashboard.
- Display videos using a shortcode or widget.

## Usage

[videos_chapters_logos id="5"]

Replace `5` with your video ID.

## Installation

1. Upload the plugin to WordPress.
2. Activate it from the Plugins menu.
3. Open **Videos Chapters** to manage your videos.
